# 章节识别规则说明

> 对应 `src/core/recognizer/`。规则以数据结构表达（`rules.ts`），识别管线是纯函数（`index.ts`），
> 可在主线程或 Web Worker 中调用。本文说明"为什么这么切"。

## 1. 管线

```text
归一化文本
  → ① 分行（保留每行全文偏移）
  → ② 候选行扫描：多套规则并行逐行匹配，取每行命中里权重最高的一条
  → ③ 方案打分：0.5×规则权重 + 0.2×覆盖度 + 0.2×连续性 + 0.1×分布均匀性
  → ④ 决策：并集方案 ≥ 0.55 且候选足够 → 采纳；否则降级
  → ⑤ 人工校正（RecognizePage）→ ⑥ 只存偏移
```

## 2. 规则表

| id | 规则 | 正则 | 权重 | 层级 |
| --- | --- | --- | --- | --- |
| `volume` | 卷 | `^第([零〇一二两三四五六七八九十百千0-9]+)卷[ ]*(.*)$` | 0.50 | 1 |
| `chapter` | 章 / 节 / 回 | `^第([零〇一二两三四五六七八九十百千万0-9]+)[章节回][ ]*(.*)$` | 0.90 | 2 |
| `english-chapter` | 英文 Chapter | `^(Chapter\|CHAPTER)\s+([0-9]+\|[IVXLCDM]+)(?![A-Za-z0-9])\s*(.*)$` | 0.90 | 1 |
| `special` | 特殊标题 | `^(序章\|楔子\|引子\|前言\|序言\|尾声\|后记\|番外\|终章\|完结)([\s·:：—-].{0,20})?$` | 0.85 | 1 |
| `numeric` | 数字标题 | `^\s*([0-9]{1,4})[、.．:：]\s*\S.{0,30}$` | 0.60 | 1 |
| `blank-line` | 空行短行启发式 | 长度 ≤ 20、前后空行、无密集标点 | 0.30 | 仅降级 |

匹配前会先剥离装饰（`★ 【】 《》 ●` 等）再匹配，但展示保留原始标题。

## 3. 两条容易踩错的判定

**① 标题行 vs 正文句**

- 只把「。」当作正文的强标志：标题里出现 `？！，、` 是常态（例：`第二十六章 凛冬将至！`、
  `第五十章 放火烧山，牢底坐穿`），早期版本把这些也算句末标点，导致一本 3866 章的书漏掉 36 章。
- 以逗号/顿号结尾的行按"被硬折行的正文下半句"处理，直接排除。
- 以引号开头、长度 > 80 的行一律排除。

**② 单层方案为什么取并集**

文档原设计是「每条规则各自成一个方案，比分数取最高」。实测混合排版会出事：
一本以 `第一章…` 为主、夹杂 `序章 / 楔子 / 尾声 / 番外` 的书，纯章号方案分数更高（0.95 vs 0.78），
于是序章与尾声被整段丢掉。现在单层方案取**所有单层规则命中行的并集**（行级去重、权重取最大值），
卷规则单独用于「卷 > 章」两级降级。备选方案里仍保留各单规则的切分结果，供校正页切换。

## 4. 打分

```text
score = 0.50 × r       规则权重
      + 0.20 × c       覆盖度：命中数 / (字数/3000)，ratio<0.5 线性衰减，1–3 给满分，>3 按 3/ratio 扣
      + 0.20 × m       连续性：相邻序号 +1 计 1 分、跳号计 0.6、重号/回退计 0；无序号按 0.5 中性
      + 0.10 × p       均匀性：落前 5% 的命中视为噪声，p = 1 - 头部占比
```

## 5. 决策与降级

1. 并集方案 `score ≥ 0.55` 且候选数 ≥ 3 → `chapter-regex`
   （文本 < 9000 字时最少候选放宽到 1，否则短篇只有 1–2 章会被误判为"识别失败"）
2. 有卷且有章 → `volume-chapter`（卷 level 1，卷内章 level 2）
3. 文本 ≥ 3000 字 → `char-count`（每 3000 字，优先在段落空行处断开）
4. 空行短行 ≥ 3 处 → `blank-line`
5. 否则 `single`（整篇一章，提示手动切分）

第一章之前若有 > 500 字的整段（内容简介、前言），会单独列为「前言」章节，避免这部分正文没入口。

## 6. 人工校正

`RecognizePage` 支持：改标题（逐行输入框）、与下一章合并、从选中段落拆分、删除（正文并入上一章）、
重跑识别。所有人工结果记为 `source: 'manual'`、`confidence: 1`；
重跑时默认**保留人工边界**（人工与自动边界取并集，人工标题优先），要全部重算可先手工清空。

## 7. 验收数据（2026-11-26）

- 合成样例库：10 种风格，57 个预期章节，**召回 100% / 精度 100%**
- 真实书库（本地样本，书名不入库）：19.2MB、GB18030、963 万字，识别 3873 段（文件名宣称 3866 章，
  多出的 7 段来自简介/预告区的章节样式行），得分 0.943，识别耗时 **61ms**（目标 < 300ms）
